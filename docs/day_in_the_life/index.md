| System Admin| Responsible for hardward and software, including upgrades, patches, and system resources | [go to guide](https://treisland.github.io/fortify_sysadmin_guide/)

| DevOps | Automates security through build pipelines following the **Security As Code** methodology  | [go to guide](https://treisland.github.io/fortify_devops_guide/)
| Security Analyst | Reviews and audits vulnerabilities from security scans.  May also be responsible for report generation | [go to guide](https://treisland.github.io/fortify_security_analyst_guide/)
| AppSec Lead | Monitors and reports on the application security program, usually involving dashboarding and metrics | [go to guide](https://treisland.github.io/fortify_appsec_guide/)
