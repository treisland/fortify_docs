| Role | Description |
| ---- | ----------- |
| System Admin| Responsible for hardward and software, including upgrades, patches, and system resources |
| Developer | Programs applications and is responsible for code changes and remediation of vulnerabilities |
| DevOps | Automates security through build pipelines following the **Security As Code** methodology  |
| Security Analyst | Reviews and audits vulnerabilities from security scans.  May also be responsible for report generation |
| AppSec Lead | Monitors and reports on the application security program, usually involving dashboarding and metrics |
