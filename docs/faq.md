# Frequently Asked Questions

> Find answers to common questions regarding the Fortify platform

??? question "Where can i find the SSC API documentation"

    **Software Security Center** provides a robust API that can be found directly within the web portal.

    The documentation provides guidance on how to authenticate to the API and also how to use the Swagger interface to test the endpoints.

    <!-- more -->

    1. Log into the SSC portal


    1. In the upper right corner click the question mark icon :octicons-question-24:.


    1. A model window will appear with links to documentation.

        - **API Documentation** link will explain how to authenticate and use the API.

        - **API Reference will** take you to the Swagger interface were the API endpoints can be seen and tested
